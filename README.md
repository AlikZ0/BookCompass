# BookCompass 1.4 — расширение BookVoice 1.3

> **Статус:** исходники и сборка через GitHub Actions подготовлены. Swift-синтаксис, основные Foundation-модели, ZIP и локальное хранилище проверены в Linux. Полная компиляция с iOS SDK и работа на реальном iPhone **ещё не подтверждены**. При проблеме в Actions ищите первую `error:`, а не меняйте runner без причины.

BookCompass использует **тот же Bundle ID и хранилище BookVoice**, чтобы при корректном обновлении не потерять старые PDF и прогресс. Новый заголовок приложения в системе — `BookCompass`, но имя Xcode-таргета, схема, имя `.app`, каталог `Application Support/BookVoice` и исходные модели сохраняются.

## Экраны

1. **Библиотека:** прежние книги, прогресс чтения, число заметок, кнопка «Мои знания».
2. **Чтение:** PDF, старый TTS-плеер/таймер/голоса; кнопки «Запомнить», «Цитата», «Голос»; выбор фрагмента текста PDF через `PDFSelection`.
3. **Заметки:** список с фильтрами «Все», «Текст», «Голос», «Избранное», поиск по русским и армянским строкам, тегам.
4. **Карточка заметки:** цитата, комментарий, теги, запись M4A, прослушивание, редактирование, удаление и переход на страницу книги.
5. **Повторение:** избранные заметки, оценки «Помню»/«Повторить позже», простое расписание 1/3/7/14/30 дней, история оценок.
6. **Карта тем:** ручные теги → связанные заметки и названия книг; без автоматического AI и графа.
7. **Резервное копирование:** JSON + M4A в ZIP, PDF включаются **только по выбору**; импорт добавляет записи с защитой UUID-коллизий.

## Сохранение старых данных

Оригинальные файлы BookVoice 1.3 **не меняют свой формат**:

```text
Application Support/BookVoice/
├── library.json                 # BookVoice 1.3, не перезаписывается при обновлении
├── Books/<uuid>.pdf             # старые книги остаются на месте
├── annotations.json             # НОВЫЙ атомарный файл заметок
└── VoiceNotes/<uuid>.m4a        # НОВЫЕ локальные аудиозаметки
```

`AnnotationStore` не перезаписывает повреждённый `annotations.json`; в этом случае открывается режим только для чтения, а ошибка видна в разделе «Знания». JSON использует ISO-8601 даты. Устаревший `library.json` по-прежнему декодируется оригинальным `BookLibrary` без миграции.

**Не удаляйте приложение перед установкой обновления**, иначе iOS может удалить локальный контейнер вместе с книгами. Подписывайте следующую версию **тем же Apple Team и Bundle ID** и ставьте поверх текущей. При смене Team или Bundle ID система может создать новое приложение с пустой библиотекой. Перед обновлением сохраните копию данных доступными средствами.

## Этапы реализации

- **A:** атомарное хранилище, цитаты, закладки, теги, поиск, переход к странице и выделение на PDF.
- **B:** запись локальных M4A, воспроизведение, избранное и расписание повторений.
- **C:** темы на базе тегов; экспорт ZIP и безопасный импорт без замены старой базы.

## Известные ограничения

- В сканированных PDF распознанный текст можно копировать из отдельного окна и отредактировать перед сохранением. Система **не знает точные координаты** каждого распознанного предложения на PDF-изображении.
- Для обычного PDF выбор через PDFKit зависит от наличия текстового слоя. Повторное открытие заметки переходит на страницу и пытается подсветить начало цитаты, если текстовый слой есть.
- Голосовая запись не является транскрипцией. Нужен разрешённый микрофон. При записи чтение книги ставится на паузу, чтобы не смешивать звук. Продолжить прослушивание можно вручную.
- Голоса RU/EN/HY зависят от установленных голосовых пакетов iPhone. При отсутствии голоса на языке возможен неестественный звук, приложение не скачивает сторонние модели.
- Резервные ZIP используют стандартный **method 0 (без сжатия)**; импортер целенаправленно поддерживает архивы собственного формата, а не произвольные ZIP с Deflate/ZIP64. Действует ограничение 90 МиБ на один файл и 240 МиБ в сумме. Для больших PDF нужен другой экспорт.
- Расписание повторений ручное, без уведомлений и облачного AI. При удалении PDF с сохранением заметок переход на страницу становится недоступен, пока книга отсутствует.
- Нет серверов, логина, рекламных SDK, OCR в облаке, SwiftData и внешних Swift Package-зависимостей.

## GitHub Actions: установка без Mac

1. Скачайте ZIP проекта или ZIP-обновления. В **существующем** репозитории BookVoice 1.3 замените изменённые файлы, добавьте новые. Директории `BookVoice/BookVoice` внутри другого `BookVoice` быть не должно.
2. Если вы использовали собственный `PRODUCT_BUNDLE_IDENTIFIER` в `project.yml`, сохраните его: пример в ZIP имеет прежнее значение `com.example.BookVoice`.
3. Проверьте `.github/workflows/ios.yml`. Если у вас старый дублирующий `main.yml` с тем же назначением, отключите один из них.
4. Commit в `main` → **Actions → Build BookCompass for iPhone**.
5. При зелёной сборке скачайте `BookCompass-unsigned-IPA`, распакуйте GitHub artifact и извлеките `.ipa`.
6. **IPA неподписанный**. Для установки потребуется отдельно подписать его с помощью инструмента, поддерживающего ваш iPhone и профиль Apple. Бесплатный профиль обычно требует обновлять подпись через 7 дней; количество активных приложений ограничено.
7. Устанавливайте поверх существующей версии с тем же Bundle ID, чтобы сохранить PDF и прогресс. Сначала сделайте резервную копию.

Для unit-тестов: **Actions → BookCompass unit tests → Run workflow** (отдельный ручной workflow). Он требует доступного iPhone Simulator на macOS runner.

## Ручной чек-лист на iPhone

- [ ] Запуск после обновления: прежние PDF видны, последний открытый номер страницы тот же.
- [ ] Добавить PDF с текстовым слоем; выделить предложение; «Цитата» → добавить теги; закрыть/открыть приложение; поиск по цитате.
- [ ] Во время чтения нажать «Запомнить»; проверить привязку страницы и переход из карточки заметки.
- [ ] Импортировать скан: открыть окно OCR, скопировать нужный текст и сохранить; не ждать точной подсветки на изображении.
- [ ] Создать голосовую заметку, разрешить микрофон, закончить запись, прослушать M4A; проверить отказ в доступе к микрофону.
- [ ] Пометить заметку избранной; «Помню» и «Повторить позже» меняют дату; история фиксируется.
- [ ] Создать русские и армянские теги, открыть карту тем, найти цитату в тематическом разделе.
- [ ] Экспортировать ZIP без PDF и проверить отсутствие `books/*.pdf`.
- [ ] Экспортировать ZIP с PDF, проверить наличие книги и её прогресса на втором чистом устройстве.
- [ ] Повторно импортировать один и тот же ZIP: не должно быть повторяющихся заметок/голосовых записей.
- [ ] Удалить одну книгу (с заметками / без); остальные книги и прогресс не должны измениться.
- [ ] Запустить TTS, заблокировать экран, проверить фоновое воспроизведение; затем открыть голосовую запись и проверить отсутствие наложения звука.
- [ ] Проверить ошибки: пустой текст, отказ микрофона, PDF без текста, повреждённый JSON и ZIP, отсутствие места на устройстве.

## Проверки, выполненные при подготовке

- Локальный `swiftc -frontend -parse` всех Swift-файлов.
- На Linux выполнена частичная проверка типов Foundation-моделей, `AnnotationStore`, `BookLibrary` (с тестовыми заглушками для iOS-only фреймворков), `BackupService` и ZIP.
- Реальные тесты в Linux: ZIP round-trip/CRC/unsafe path, локальное сохранение/повторное открытие заметок, армянский/русский текст, план повторений, безопасный повторный импорт и запрет перезаписи повреждённого JSON.
- Проверен YAML XcodeGen и GitHub Actions на корректный синтаксис.

**Xcode 16.4 archive и запуск на устройстве здесь не выполнялись; код может потребовать правок после первой CI-сборки.**

# BookCompass 1.4.1 — исправление записи голосовых заметок

## Симптом

Диалог «Не удалось сохранить / Не удалось открыть голосовую запись» в BookCompass 1.4. Старая версия объединяла разные ошибки AVAudioRecorder и проверки файла в один `CompassError.invalidAudio`, поэтому по тексту невозможно было понять точный этап сбоя.

## Изменения

- `BookVoice/Services/VoiceNotesAudio.swift`: отдельные ошибки начала записи, подготовки, прерывания, отсутствующего, слишком короткого или некорректного M4A. Проверяется `prepareToRecord()` и `record()`; после `stop()` проверяются существование файла, его размер и читаемость через `AVAudioPlayer`. Используется AAC, 44.1 kHz, mono. При неудаче удаляется только повреждённая новая запись.
- `BookVoice/Services/BookSpeechPlayer.swift`: синтез речи полностью прекращается перед записью, чтобы освободить аудиосессию. UUID книги, текущая страница и PDF-прогресс библиотеки не удаляются. Последняя произносимая позиция внутри страницы может быть потеряна: при продолжении страница начнёт читаться заново.
- `BookVoice/Views/Knowledge/VoiceNoteSheet.swift`: отдельные заголовки ошибок начала/сохранения; кнопка сохранения недоступна до 1 секунды; подтверждение выхода при активной записи; отмена запоздалого запроса доступа к микрофону.

## Обновление в существующем GitHub-репозитории

1. В корне репозитория замените три Swift-файла из `BookCompass-voice-fix-patch.zip`, сохранив директории.
2. **Не заменяйте `project.yml` из другого проекта, если у вас есть собственный `PRODUCT_BUNDLE_IDENTIFIER`.** Для патча менять конфигурацию не требуется.
3. Commit в `main` → Actions → `Build BookCompass for iPhone`.
4. Скачайте unsigned IPA только из успешного нового запуска, подпишите тем же Team / Bundle ID и установите поверх прежнего приложения.
5. Не удаляйте старое приложение: заметки, книги и история чтения хранятся в его контейнере.

## Проверка на iPhone

1. Настройки iOS → Конфиденциальность и безопасность → Микрофон: у BookCompass должен быть доступ (если приложение присутствует в списке).
2. Откройте книгу → «Голос» → «Начать запись». При первом запуске разрешите доступ к микрофону.
3. Говорите минимум 2–3 секунды, затем нажмите «Остановить и сохранить».
4. Откройте «Знания» → заметка → «Слушать». Запись должна воспроизводиться.
5. Проверьте повторную запись после включённого TTS, отказ в доступе и закрытие формы во время запроса разрешения.
6. Если снова будет ошибка, сообщите точный **новый текст**. Теперь он указывает на этап сбоя.

## Статус проверки

Локально проверен синтаксис всех Swift-файлов (`swiftc -frontend -parse`), структуры архивов, конфигурация микрофона в `project.yml`. **Полный `xcodebuild archive` на macOS и реальный микрофон iPhone не проверялись.** Это исправление вероятных причин и усиление диагностики, а не подтверждённое исправление по логу устройства.
